Jev：不聊天的 AI 决策模型

不聊天不写代码，只做判断题的 AI
👀 日常场景

技术新闻突然刷屏："一个不聊天、不写代码的 AI 模型火了"。它不陪你说话，只做判断题——"用户想订机票吗？""这条评论违规几分？"据官方称又快又便宜还"不可能幻觉"。这到底是营销话术，还是 Agent 时代真缺了这么个零件？

原理：它是怎么运作的

💡 不生成自由文字、不聊天：输入状态描述+预定义问题，直接返回带概率的结构化决策——Agent 流水线里专做"小判断"的零件。

先看全过程

  1. 写一段状态描述 + 预定义好问题
  2. 问题分三类：选择题 / 评分题 / 是非题
  3. Jev 平行作答，不逐字生成文字
  4. 直接返回结构化决策 + 概率
  5. 附带 confidence 置信度
  6. Agent 拿着结构接着干活

先看它和 LLM 的根本区别。LLM 逐字生成文字：问“用户想订机票吗”，它一个字一个字往外蹦，程序还得再解析成 true/false。Jev 反过来：一次性摆好所有问题（选择/评分/是非），平行作答，直接返回机器可用的结构——{“订机票”: 0.91}，附带 confidence（置信度）。

为什么快？据官方称，LLM 慢在自回归生成，Jev 跳过这条管线；官方宣称快两个数量级，但这是单方说法，第三方反馈加速 5-18 倍，尚待独立验证。

为什么“结构上不可能幻觉”？幻觉是自由文本的副产品；Jev 的输出被锁死在预定义选项里，只能选、不能编——当然选错也是一种错。

名字取自经济学家 Jevons（杰文斯悖论），“System One”致敬《快思慢想》。定位：不取代 ChatGPT，而是 Agent 流水线里做小判断的零件。TypeSafe AI 创始人 Diogo Almeida 曾是 OpenAI 研究员（InstructGPT 作者之一），训练方式官方称 RLCD。目前 early access，单次选项上限 255，官方刻意不公布 benchmark 成绩。

我该怎么用它

  • 官方 Playground 免代码试用：打开网页就能玩：写一段状态描述，选"选择题/评分题/是非题"，点一下看它返回决策和概率
  • 新账号 5 美元免费额度：约 1.2 亿 token 的输入量，个人尝鲜完全够用，输出还免费
  • API / 官方 Skill（进阶）：把 Jev 接进自己的程序或 Claude Code，让 Agent 拿它做小判断
  1. 去 TypeSafe 官网注册，领 5 美元免费额度，进 Playground
  2. 先玩官方示例：比如"客服退款分流"，看输入一段话、返回带概率的决策是什么感觉
  3. 换成你自己的场景：写一段状态描述，加一道选择题或评分题
  4. 对比一下：同样的问题丢给 ChatGPT——体会"聊天"和"做判断"是两种活
  5. 觉得有用，再考虑 API：按官方文档拿 Key，从小流量开始试
