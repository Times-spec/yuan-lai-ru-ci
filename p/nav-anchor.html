跳转与导航

锚点跳转

长页面里的电梯，直达指定楼层
👀 日常场景

看一篇很长的产品说明书，顶部目录点“第三章”，页面“唰”地一下滑到对应位置，地址栏多了个 #chapter3。这就是锚点跳转：同一页面内的瞬间传送。地址栏里那个 # 号，就是这趟短途旅行的车票。

原理：它是怎么运作的

💡 URL 末尾的 #片段标识对应页面里某个元素的 id，点击后浏览器直接滚动到该元素，全程不向服务器发请求。

先看全过程

  1. 链接地址末尾带上 #元素id
  2. 浏览器解析出片段标识
  3. 在页面中找到对应 id 的元素
  4. 平滑滚动到该元素位置
  5. 整个过程不请求服务器

锚点是长页面里的“电梯”：URL 末尾的 #chapter3 对应页面里 id="chapter3" 的元素，点击后浏览器直接滚动到该元素，全程不向服务器发任何请求——# 后面的片段标识根本不会被发出去。浏览器还会把它记进历史记录，所以点回退能回到之前的位置。它看似简单，工程里有几个坑：页面顶部有固定导航栏时会遮住目标标题，要用 scroll-margin-top 预留空间；内容是 JS 异步加载的，锚点可能定位到还没撑开的位置；id 必须全页唯一，重复了只会跳到第一个。想做得精致，加一行 scroll-behavior: smooth 让滚动顺滑，再用 :target 伪类给当前定位的章节加个高亮，文档站的体验立刻上一个台阶。还有一个冷知识：# 后面的内容不会发给服务器，所以有人拿它在前端存状态（比如当前选中的标签页），刷新页面状态还在，又不污染后端日志。但别指望靠它给后端传参，那是缘木求鱼。

网站是怎么做到的

  • #片段标识：不发给服务器的车票：URL 里 # 后面的内容根本不会被发出去。浏览器只在本地用它找元素、滚动，全程零请求。
  • scroll-margin-top：给顶栏让路：页面顶部有固定导航栏时，会遮住跳转目标的标题。给目标加 scroll-margin-top 预留空间。
  • scroll-behavior: smooth：一行变顺滑：加一行 CSS，跳转从“唰地闪现”变成平滑滚动，体验立刻上一个台阶。
  • :target 高亮：告诉你“在哪”：用 CSS 的 :target 伪类，给当前定位到的章节加个高亮背景。
  1. 你点目录里的“第三章”，链接地址是 page#chapter3
  2. 浏览器解析出 # 后面的“chapter3”
  3. 在页面里找到 id=“chapter3” 的元素
  4. 平滑滚动到该元素的位置
  5. 浏览器记下这次跳转，点回退能回到之前的位置
