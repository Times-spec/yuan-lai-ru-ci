网页二维码生成

一行链接，变成手机能扫的码
👀 日常场景

电脑上看到活动页面，旁边放着一个二维码，手机一扫就打开了——不用手动一字字输网址。会议签到、海报引流、WiFi 分享，凡是“电脑有链接、手机要打开”的地方，都有它在 bridge 一下。

原理：它是怎么运作的

💡 把网址按 QR 编码规则转成黑白方块矩阵，前端用库画在 canvas 上，扫码即还原原文。

先看全过程

  1. 拿到要分享的网址文本
  2. 按 QR 编码规则转成二进制
  3. 选择纠错等级与尺寸
  4. 用库绘制黑白方块矩阵
  5. 渲染到 canvas 或图片展示
  6. 支持下载或打印分享

二维码本质是“把文字画成图”。QR 码有一套公开的编码规则：先把网址按模式（数字/字母/字节）转成二进制，再按纠错等级（L/M/Q/H，最高可容忍 30% 的污损）加上纠错码，最后排进一个黑白方块矩阵，周围留一圈空白（quiet zone，静区，扫码定位用）。前端生成完全不需要服务器：qrcodejs 这类库在浏览器里算出矩阵，用 canvas 把方块画出来就行，所以“网页二维码”通常是纯前端功能，离线都能用。为什么手机一扫就知道是网址？因为编码时就约定好了内容格式，扫码 App 解码后看到 http 开头就直接打开。两个实用知识点：一是“动态码 vs 静态码”——静态码内容写死，网址变了码就废；动态码背后是个短链接，改短链指向就能换目标，还能统计扫码量，营销场景都用动态码。二是美化二维码（中间放 logo、改颜色）会遮挡部分方块，必须用高纠错等级兜底，否则扫不出来。

我该怎么生成二维码

  • 微信 / 支付宝里搜：搜“二维码生成”就有小程序，粘贴链接点生成，存到手机相册就能用。最顺手。
  • 浏览器在线工具：电脑上打开二维码生成网站，粘贴网址就能生成，还能调尺寸、下载高清 PNG 拿去印刷。
  • 动态码（长期用选它）：二维码背后藏的是短链接，目标网址变了改短链指向就行，还能统计被扫了多少次。
  1. 先把链接准备好：越短越好，长链接先压成短链
  2. 打开生成工具（小程序或网站），把链接粘贴进去
  3. 要往中间放 logo？把纠错等级选到最高（H 级），否则遮挡后扫不出
  4. 生成后别急着发布：拿两三款不同手机实测都能扫出来
  5. 下载高清 PNG，需要印刷的直接给印刷厂
