H5 跳小程序

网页里一点，直接蹦进小程序的指定页面
👀 日常场景

在微信里看到一篇公众号文章，文末“点击预约”按钮一点，直接跳进了商家的小程序预约页，全程没离开微信，也没扫码。这就是 H5 跳小程序。点一下按钮，网页就“变身”成了小程序的某个页面。

原理：它是怎么运作的

💡 微信等超级 App 给网页开了专用通道：网页调用 JS-SDK 或使用特定标签，就能直接拉起小程序并传参。

先看全过程

  1. 网页接入平台 JS-SDK
  2. 用户点击跳转按钮
  3. 调用跳转接口并传入小程序路径
  4. 超级 App 拦截并拉起小程序
  5. 小程序按参数打开指定页面

微信、支付宝这类超级 App 给外部网页开了一条“直达电梯”。在微信里，H5 页面引入 JS-SDK 并完成签名配置后，可以用 <wx-open-launch-weapp> 标签包裹一个按钮，用户一点就直接拉起指定的小程序并跳到对应路径，全程不用扫码、不用离开微信。微信之外的地方（短信、邮件、别的 App 的浏览器）则可以用小程序的 URL Link 或 URL Scheme：它们本质是一条普通的 https 短链，微信能识别并转成打开小程序。这套机制的门槛在配置：小程序后台要配业务域名、JS-SDK 签名、原始 ID，任何一个对不上都会静默失败，调试时只能真机一个个排查。另外记住：wx-open-launch-weapp 标签只在微信客户端内有效，放到普通浏览器里点它毫无反应，跨平台页面要做好环境判断。

开发者：应该如何接入

  • wx-open-launch-weapp 标签：微信内 H5 直接拉起小程序
  • 小程序 URL Link：一条普通 https 链接，微信外也能打开小程序
  • 小程序 URL Scheme：可配有效期和参数的短码链接
  1. 在小程序后台配置业务域名，或生成 URL Link
  2. H5 页面引入微信 JS-SDK 并完成签名配置
  3. 用 <wx-open-launch-weapp> 标签包裹跳转按钮
  4. 传入 username（小程序原始 ID）与 path 参数
  5. 真机多环境测试：微信内、朋友圈、安卓与 iOS
