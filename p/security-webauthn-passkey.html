WebAuthn/指纹面容登录

按一下指纹就登录，密码从此可以消失
👀 日常场景

在手机上打开某个网站，点登录后直接弹出“请验证指纹”，按一下就进去了——全程没输过密码。你不禁疑惑：网站又没见过我的指纹，它怎么知道按指纹的是我？而你的指纹数据，其实从来没离开过手机。

原理：它是怎么运作的

💡 FIDO2 公私钥挑战应答：私钥永不出设备，指纹只在本地解锁私钥。

先看全过程

  1. 注册时设备生成一对公私钥
  2. 私钥锁在设备安全芯片里，公钥存服务端
  3. 登录时服务端下发随机挑战串
  4. 用户指纹/面容在本地解锁私钥
  5. 设备用私钥对挑战串签名返回
  6. 服务端用公钥验签，防钓鱼

WebAuthn（FIDO2 协议族）的设计哲学是“没有密码可偷”。注册时，你的手机/电脑在安全芯片里生成一对公私钥：私钥永不出设备，公钥传给网站存着。登录时网站发一个随机挑战串（challenge），设备要求你用指纹或面容在“本地”解锁——注意，指纹数据从不出设备，它只是开锁的钥匙。解锁后设备用私钥给挑战串签名，把签名发回网站；网站用存着的公钥验签，验过即登录。这里有三重精妙：一是每个网站的密钥对都不同，A 站数据泄露不影响 B 站；二是签名里绑定了网站域名，钓鱼网站拿到的签名在真站上验不过——这是 Passkey 天生防钓鱼的原因；三是苹果/谷歌现在支持把私钥加密同步到 iCloud/谷歌账号（即 Passkey），换手机也能无缝迁移，解决了“丢设备=丢账号”的老大难问题。它的普及只差临门一脚：主流浏览器和手机系统都已内置支持，剩下的主要是网站的接入意愿和用户教育。

我该怎么用它

  • iCloud 钥匙串：苹果生态自动同步，iPhone 上创建、Mac 上直接用
  • Google 密码管理工具：安卓手机和 Chrome 之间同步通行密钥
  • YubiKey 硬件密钥：插 USB 或碰一下 NFC 完成验证，物理隔离最放心
  1. 在网站的“账号安全”设置里找到“通行密钥 / Passkey”，点“添加”
  2. 按提示用指纹或面容确认一次——这一步只在你的设备本地完成
  3. 给这个密钥起个名字（如“我的 iPhone”），方便以后管理
  4. 下次登录时选“使用通行密钥”，指纹按一下就进去了，不用输密码
  5. 换手机时登录原来的云账号（Apple ID / Google 账号），密钥会自动同步过来
