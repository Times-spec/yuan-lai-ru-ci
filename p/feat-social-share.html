社交分享

一键把页面发到微信、微博
👀 日常场景

看到一篇好文章点“分享”，弹出微信、微博、QQ 几个选项，点一下就跳过去，标题和链接都已经填好了。你在微信里看到的那些带标题、摘要、配图的链接卡片，也是这套机制的功劳。

原理：它是怎么运作的

💡 移动端调用系统分享面板（navigator.share），桌面端拼接各平台的分享链接跳转，标题摘要通过 Open Graph 标签提供。

先看全过程

  1. 准备好标题、摘要与配图
  2. 页面加上 Open Graph 标签
  3. 移动端调 navigator.share 拉起面板
  4. 桌面端拼接平台分享链接
  5. 用户选平台完成分享
  6. 统计分享带来的回流

分享功能分“系统级”和“手工拼”两路。移动端有系统级方案：Web Share API，调用 navigator.share({title, text, url})，浏览器直接拉起手机原生的分享面板，体验最顺，但它要求 HTTPS 且必须由用户点击触发，桌面端支持不一，所以要做特性检测。桌面端主要靠“手工拼”：各平台都提供了分享跳转链接，比如微博是 service.weibo.com/share/share.php?url=...&title=...，把当前页面的标题和地址拼进去，用户一点就跳到该平台的发布页，内容已经填好。想让分享出去的链接显示漂亮的标题+摘要+配图卡片，靠的是 Open Graph 标签（og:title、og:description、og:image）：平台爬虫抓取页面时读这些标签生成卡片。微信是个特例：在微信内置浏览器里，navigator.share 不可用，得用微信 JS-SDK 的 updateAppMessageShareData 来自定义右上角分享出去的内容，还要先配置 JS 安全域名。兜底方案永远是“复制链接”，分享面板调不起来时至少让用户能手动发。

网站是怎么做到的

  • Web Share API：系统的分享面板：调一下 navigator.share，浏览器直接拉起手机原生的分享面板，微信、微博、备忘录都在里面，体验最顺。
  • 手工拼接：各平台的分享链接：微博、QQ 都有现成的分享跳转地址，把标题和网址拼进去就行。点一下跳到对应平台的发布页，内容已填好。
  • Open Graph：链接卡片的化妆师：og:title、og:description、og:image 这几个标签，是平台爬虫生成“标题+摘要+配图”卡片的原料。
  • 微信例外：JS-SDK：微信内置浏览器里系统分享不可用，得接微信 JS-SDK，还要配置安全域名。
  1. 你点“分享”，页面先检查支不支持系统分享 API
  2. 移动端：拉起手机原生分享面板，你选微信/微博
  3. 桌面端：弹出分享菜单，每个图标背后都是一条拼好的平台分享链接
  4. 你选定平台，跳转过去，标题和链接已经填好
  5. 对方点开你分享的链接：平台爬虫早就读过 OG 标签，展示出漂亮卡片
