暗黑模式

一键换肤，深夜刷手机不刺眼
👀 日常场景

晚上关灯刷手机，打开 App 点一下月亮图标，整个界面“唰”地变成深色，眼睛瞬间舒服了。更贴心的是，下次打开它还记得你的选择——不用每天调一遍，深夜党狂喜，从此告别被亮瞎眼。

原理：它是怎么运作的

💡 用 CSS 变量定义两套配色，切换 html 上的 dark 类，用户偏好存 localStorage，并跟随系统主题。

先看全过程

  1. 用 CSS 变量定义全部配色
  2. 准备深浅两套变量值
  3. 切换 html 上的 dark 类
  4. 用户偏好存入本地
  5. 首次按系统主题初始化
  6. 监听系统主题变化跟随

暗黑模式的本质是“换肤”，现代做法靠 CSS 变量。先把所有颜色抽成变量（--bg、--text、--card），浅色主题给一组值，深色主题给另一组；切换时只改 html 元素上的一个类（.dark）或 data-theme 属性，整站颜色瞬间全换，不用碰任何组件代码。用户的选择存在 localStorage 里，下次打开直接读；首次访问则读系统的 prefers-color-scheme 媒体查询（跟着手机系统的深浅走）。进阶做法是“三态”：跟随系统 / 强制浅色 / 强制深色。坑主要在三处：一是“漏网之鱼”：某处颜色写死了色值没走变量，切深色后那一块亮得刺眼；二是“首屏闪烁”：主题初始化脚本放太晚，页面先以浅色闪一下才变黑，解决办法是把一小段内联脚本放在 head 最前面；三是图片和第三方组件：纯白底图片在深色下会像“补丁”，可以用滤镜压暗或准备深色版图。Tailwind 这类框架用 dark: 前缀，本质也是类切换，只是写法更顺。

深色模式跟我有什么关系

  • 晚上刷手机眼睛更舒服：暗光下深色界面对比度低，不刺眼。睡前刷手机党、夜猫子的刚需。
  • OLED 屏幕更省电：OLED 屏的黑色像素是不发光的，深色界面直接省电。LCD 屏没这个效果（背光一直亮着）。
  • 跟随系统最省心：设一次“跟随系统”，手机切深色 App 就跟切，不用每个 App 单独调。
  1. 在 App 或网站的设置里找到“深色模式”/“外观”
  2. 选“跟随系统”（推荐）：手机深色它就深色
  3. 或者手动固定深色 / 浅色，不随系统变
  4. 选完立即生效，下次打开还记得你的选择
