预训练：海量文本喂出的通用能力

预测下一个词，练出通用智能
👀 日常场景

"GPT-3 用了 45TB 文本训练""训练一次花几千万美元"——钱到底烧在哪了？其实是烧在让模型玩一个极其昂贵的"猜词游戏"，而这个游戏恰恰不需要任何人工标注。

原理：它是怎么运作的

💡 在海量无标注文本上玩"预测下一个词"的自监督游戏，免费教材练出通用能力，世界知识是副产品。

先看全过程

  1. 爬取海量无标注文本
  2. 清洗去重，过滤垃圾
  3. 切成 token 序列
  4. 玩"预测下一个词"游戏
  5. 猜错就反向传播调权重
  6. 万亿 token 后涌现通用能力

训练 AI 最大的拦路虎是标注数据：请人一条条标注"这是猫"，又贵又慢，撑不起百亿参数。预训练的天才之处在于发现了免费教材——互联网文本本身。

玩法叫自监督学习：把一句话的最后一个词遮住，让模型猜。"中国的首都是___"，猜"北京"。猜对了没奖励，猜错了调权重。互联网上有万亿级别的句子，每一句都是一道免费的练习题。模型为了猜准下一个词，被迫学会语法、事实、逻辑、文风——世界知识是这个游戏的副产品。

在逻辑链上，预训练是"规模化"的起点：Token/Embedding 解决了输入表示，Transformer 解决了可并行放大的结构，预训练把"免费数据×大结构×大算力"拧在一起，第一次练出了通用语言能力。但它留下两个坑：模型只会续写不会听指令（下一环 SFT 解决），以及知识冻结在训练截止日（RAG 解决）。

想深入了解怎么办

  • Andrej Karpathy 的 nanoGPT：从零手写一个小 GPT，B 站/YouTube 有全程视频
  • HuggingFace 基座模型体验：下载 Qwen/Llama 的 Base 版，亲手试"它只会续写"
  • 数据工程讨论：各实验室的技术报告里关于数据清洗配比的部分
  1. 先理解自监督："遮住最后一个词让它猜"——免费教材的来源
  2. 跑 nanoGPT 或 tiny 实验，看损失是怎么降下来的
  3. 亲手对比 Base 版和 Instruct 版：同一个问题，一个续写、一个回答
  4. 了解数据清洗：去重、过滤为什么占这么大篇幅
  5. 最后看缩放定律那篇：预训练回答"怎么练"，缩放定律回答"练多大"
