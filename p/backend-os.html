操作系统（OS）

所有软件脚下的大地
👀 日常场景

买云服务器要选系统：Ubuntu、Debian 还是 Windows？都说“生产环境用 Linux”；Docker 号称“比虚拟机轻得多”。这些选择背后都是操作系统在起作用——它是所有软件脚下的大地，程序想干任何事，都得先经过它批准。

原理：它是怎么运作的

💡 内核是硬件与软件之间的唯一中介：CPU、内存、磁盘、网络全由它分配，程序通过系统调用向它申请资源。

先看全过程

  1. 程序发起系统调用申请资源
  2. 内核分配 CPU 时间片调度
  3. 内存分页隔离各个进程
  4. 磁盘与网络 IO 统一调度
  5. 一个进程崩溃不影响其他
  6. 用户态与内核态权限隔离

操作系统分三层：硬件（CPU、内存、磁盘、网卡）、内核（kernel）、应用程序。内核是软硬件之间的唯一中介——程序想干任何事（读写文件、发网络包、申请内存），都不能直接碰硬件，必须通过“系统调用”（syscall）向内核申请。

内核干四件事：进程管理（分配 CPU 时间片，营造“同时运行”的假象）、内存管理（分页加虚拟内存，每个进程看到独立地址空间）、文件系统（把磁盘块抽象成文件和目录）、设备与网络（统一调度 IO）。用户态和内核态的隔离是关键：应用跑在用户态权限受限，只有内核能执行特权指令。

为什么服务器都用 Linux？免费开源、可裁剪、极度稳定、包管理器一条命令装软件、云原生生态全围绕它生长。

容器和虚拟机的区别也在这里：容器共享宿主机内核，只用 namespace（视角隔离）加 cgroup（资源配额）造出“独立机器”的假象，所以轻、秒级启动；虚拟机自带完整内核，所以重、隔离更彻底。选操作系统，本质上是在选生态。

该怎么选系统

  • Ubuntu Server LTS：资料最多、云厂商默认选项，遇到问题一搜就有答案
  • Debian：极简、稳定、不折腾，装好能跑十年
  • Alpine Linux：只有几 MB，容器镜像专用
  • Windows Server：跑老 .NET Framework 应用或必须图形界面的场景
  1. 先看跑什么：Web/数据库/容器→Linux；老旧 .NET 应用→Windows Server
  2. 再看团队：大家熟哪个就用哪个，深夜排障时熟悉度就是生命
  3. 容器场景直接 Alpine；物理机/虚拟机长期跑选 Ubuntu LTS 或 Debian
  4. 只装 Server/最小化版本：桌面环境是浪费资源+扩大攻击面
  5. 建普通用户、配 SSH 密钥登录，禁用 root 远程登录
  6. 把自动安全更新打开：“能跑就别动”迟早变成肉鸡
