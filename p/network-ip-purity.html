IP 纯净度：8% 和 53% 是怎么算出来的

没有权威分数，只有各家算法
👀 日常场景

你把节点 IP 粘进检测网站，一家说“8% 极度纯净”，另一家说“53% 中度风险”——同一个 IP，两个分数打架了。到底谁在说谎？其实都没说谎：纯净度从来不是官方标准，而是各家按自己的“黑账本”打的分。

原理：它是怎么运作的

💡 纯净度=黑名单命中+滥用投诉+机器人流量占比+ASN 声誉的加权分；每家数据源和权重不同，分数打架很正常。

先看全过程

  1. 没有官方纯净度标准
  2. 黑名单：进过黑账本就扣分
  3. 投诉记录：被举报过留案底
  4. 人机比：机器人流量越高压分越高
  5. ASN 声誉：机房 ASN 天生低一档
  6. 各家权重不同，分数自然打架

这些系数的依据大同小异，无非四本账。第一本是威胁情报黑名单：这个 IP 历史上发过垃圾邮件、参与过攻击吗？进过 Spamhaus 这类黑账本就扣分。第二本是滥用投诉记录：有没有人举报过它。第三本是人机流量比：截图里 human 83.14% / bot 16.86%，bot 占比越高，越像代理或爬虫的出口。第四本是 ASN 声誉和历史行为：机房 ASN 先天低一档，而“万人梯”这种万人用过的 IP，前任的烂账全算在它头上。

为什么两家打架？因为数据源、更新频率、权重都不同。Cloudflare 是全球大 CDN，每天看到的攻击流量最多，算法天然偏保守；小检测站数据少，打分就宽松。顺带一提，IP 定位也是估算：截图里 5 家定位报出 3 个城市（休斯顿、那不勒斯、布鲁克黑文），看的是注册信息加测量，可不是 GPS。

这些分数到底是怎么算出来的

  • 黑名单与投诉记录：查 IP 是否进过威胁情报库、有无滥用投诉
  • 人机流量比：bot 流量占比越高，越像代理或爬虫出口
  • ASN 与历史行为：机房 ASN 先天扣分；同 IP 前任用户的行为也算账
  1. 复制节点 IP，粘进检测站
  2. 先看 IP 类型和 ASN，再看分数
  3. 对比两家以上：都低就是真低
  4. 分数是快照：IP 会易主，定期复测
