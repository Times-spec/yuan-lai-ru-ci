图形验证码

你看得懂、机器看不懂的那张扭曲图片
👀 日常场景

注册新账号或连续输错密码后，屏幕上弹出一张字母数字扭曲、粘连，还画着干扰线的图片，让你照着输入。你盯着看半天才认出来，心里嘀咕：这玩意儿到底在防谁？有时候你自己都认错了，气得直点换图。

原理：它是怎么运作的

💡 利用“人眼容易、机器难读”的认知难度差，拦住自动化脚本。

先看全过程

  1. 服务端随机生成一串字符
  2. 把字符扭曲、粘连、加噪声渲染成图
  3. 把正确答案存进用户会话
  4. 用户照着图输入字符提交
  5. 服务端比对会话里的答案
  6. 答对放行，答错刷新重来

图形验证码玩的是一个简单的经济学：给机器人制造的识别成本必须高于它作恶的收益。服务端先随机生成一串字符（如 K7Xm2），然后用字体扭曲、字符粘连、背景噪声线、随机旋转等手法渲染成图片，同时把正确答案存进当前用户的会话（session）里——图片本身不包含答案，所以攻击者截获图片也没用。用户输入后，后端把输入和会话里的答案比对，一致就通过。这套机制在 2000 年代效果很好，因为那时的 OCR（光学字符识别）技术确实读不懂扭曲字。但现在深度学习模型识别这种图片的准确率已经超过人类，它更多是作为“降级手段”和心理门槛存在：拦不住专业攻击者，但能挡住最粗糙的脚本批量注册。所以现代网站通常只在高风险场景（如多次输错密码后）才弹出它，而不是每次登录都用。给开发者的一条经验法则：防批量注册，图形验证码配 IP 限流就够了；防薅羊毛黑产，直接上行为验证码——让专业工具干专业的事。

网站该如何接入

  • Java Kaptcha / EasyCaptcha：Java 生态最常用的自研图形验证码库，开箱即用。
  • Python captcha 库：轻量 Python 库，可自定义字体、噪声和扭曲强度。
  • 前端 Canvas 自绘：纯前端生成展示，后端只负责校验答案。
  1. 后端生成随机字符串，用图片库渲染成带干扰的验证码图。
  2. 把正确答案存入用户 session（设置 2-5 分钟过期），图片以 base64 或接口返回给前端。
  3. 前端展示图片并提供“看不清换一张”按钮，换图时重新请求接口。
  4. 用户提交时，后端取出 session 中的答案做不区分大小写的比对。
  5. 校验通过后立即销毁该验证码，防止一次答案被重复利用。
  6. 配合 IP 限流使用，避免攻击者无限刷图做样本训练。
