代理模式：直连 / 全局 / 规则

记住一句就够：该直连的直连，该代理的代理
👀 日常场景

刚上手的人都会对着三个选项发呆：规则、全局、直连，到底选哪个？有人长期开着全局，结果国内网站越刷越慢；有人想排查问题，却不知道从哪下手。这三个模式，恰好对应三种不同的“出站决策”。

原理：它是怎么运作的

💡 规则模式按规则表逐条分流（日常主力），全局模式跳过规则全部走代理（临时排查），直连模式全部直连（等于暂停代理）。

先看全过程

  1. 打开一个网站，发起连接
  2. 规则模式：查规则表决定去向
  3. 国内网站命中 DIRECT，直接连
  4. 国外网站命中 PROXY，走节点
  5. 全局模式：不查表，全部走节点
  6. 直连模式：不查表，全部直连

一个个说。规则（Rule）模式是日常主力：每条连接过来，Clash 翻规则表——国内网站命中 DIRECT 直连，又快又不花节点流量；国外网站命中 PROXY 走节点；广告域名命中 REJECT 直接丢掉。精准、省钱、速度快，所以老玩家都说“无脑规则”。

全局（Global）模式是“一刀切”：跳过规则表，所有流量统统走代理。它不适合长期开——国内网站绕道海外再回来，只会更慢，还白白消耗节点流量。它的正确用法是临时排查：怀疑某网站被规则误伤了，切全局能打开，就说明节点没问题，是规则没写对。

直连（Direct）模式则是“暂停键”：所有流量都不经过代理，等于让 Clash 靠边站。用来回答一个关键问题：这个毛病到底是代理惹的，还是我本地网络本身就有问题？

最后记住一个关键区分：这三个是“出站模式”，回答“流量出去走哪条路”；而系统代理/TUN 是“接管方式”，回答“流量怎么被抓到 Clash 手里”。两者是独立维度，可以任意组合——比如“规则模式 + TUN”就是最常见的日常组合。

该用哪种模式

  • 规则模式（日常默认）：按规则表精细分流：国内直连、国外走代理、广告直接丢掉
  • 全局模式（临时测试）：跳过规则，所有流量走代理
  • 直连模式（故障排查）：全部直连，等于临时让 Clash 靠边站
  1. 默认：规则模式，不用动
  2. 某网站打不开：先切全局试试——能打开，说明节点没问题，是规则没写对
  3. 还是打不开：换节点；再不行切直连，看是不是本地网络的问题
  4. 定位清楚后，立刻切回规则模式
  5. 记住口诀：过日子用规则，排查用全局和直连
  6. 别把“出站模式”和“系统代理/TUN”搞混：一个管走哪条路，一个管怎么被接管
