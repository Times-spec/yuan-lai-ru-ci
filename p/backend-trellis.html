Trellis：一键配出生产服务器

一条命令，WordPress 服务器全自动上线
👀 日常场景

接了个 WordPress 建站单：买台 VPS，装 Nginx、PHP、MySQL，配 HTTPS、防火墙……手动搞一下午还容易配错。Trellis 终结这种重复劳动：一份配置加两条命令，裸服务器自动变成生产级 WordPress 环境。

原理：它是怎么运作的

💡 基于 Ansible 的 WordPress 服务器自动化方案：把“装什么、配成什么样”写成 YAML 剧本，一键把裸 Ubuntu 变成生产级 LEMP 服务器。

先看全过程

  1. trellis new 生成项目骨架
  2. 填好站点配置 YAML
  3. trellis provision 配服务器
  4. Ansible 经 SSH 自动装 LEMP
  5. Let's Encrypt 自动签发 SSL
  6. trellis deploy 零停机发布

Trellis 是 Roots 团队开源的 WordPress DevOps 工具链，底层是一套写好的 Ansible playbook（Ansible：用 SSH 批量管服务器的自动化工具，用 YAML 写“剧本”）。它分开两件事：provision（配服务器）和 deploy（发代码）。server.yml 把裸 Ubuntu 装成生产级 LEMP 栈：Nginx、PHP、MariaDB、Let's Encrypt 自动 SSL、fail2ban；deploy.yml 每次建带时间戳的发布目录，原子切换软链接——网站全程在线，还自带回滚。

配置按三套环境存放，密码用 Ansible Vault 加密后进 Git；一般搭配 Bedrock（Composer 管理的 WP 结构）使用。

核心价值：环境一致性——开发、预演、生产用同一套剧本配出来，消灭“在我机器上是好的”；可重复——服务器挂了，换一台 provision 就回来。局限：只认裸 Ubuntu VPS，虚拟主机用不了；Windows 宿主机不支持。

开发者：应该如何接入

  • Trellis：WordPress 专用，配服务器+发版一条龙
  • 手写 Ansible playbook：通用，不限 WordPress
  • 宝塔面板：点鼠标配环境，零命令行
  1. brew 安装 trellis-cli 命令行工具
  2. trellis new example.com 生成项目骨架
  3. 填写 group_vars/production/wordpress_sites.yml（域名、仓库地址）
  4. 准备一台裸 Ubuntu 24.04，配好 SSH 密钥登录
  5. trellis provision production，一键配好生产栈
  6. trellis deploy production 发布，以后发版同一条命令
