视频导出参数：采样率、位深、格式一次讲明白

精度越高越清晰，文件也越大
👀 日常场景

你在剪映里剪完视频点导出，冒出一堆选项：分辨率 1080p 还是 4K、帧率 30 还是 60、码率、编码 H.264、音频采样率 48000……全默认也能用，但发出去要么文件大得传不动，要么画质糊得没眼看。这些数字什么意思，该怎么选？

原理：它是怎么运作的

💡 这些参数本质都是“精度”的选择：用多少数据来描述声音和画面。精度越高越清晰，文件也越大；导出的艺术就是在清晰和体积之间找平衡。

先看全过程

  1. 声音是波，先“采样”再“量化”
  2. 采样率 = 一秒给声音拍多少快照
  3. 量化位数 = 每张快照有多精细
  4. 画面也一样：分辨率管精细
  5. 帧率管流畅，码率管总账
  6. 编码格式 = 怎么打包发货

声音是连续的波，存进电脑要先变成数字，分两步：采样和量化。

采样率就是一秒钟给声音拍多少张“快照”：44100Hz 是 CD 标准，48000Hz 是视频行业标准。为什么是这两个数？人耳最多听到约 20000Hz 的声音，按采样定理，采样率至少要是最高频率的 2 倍，44100 就是这么来的。剪视频直接选 48000，和画面统一标准最省心。

量化位数是每张“快照”有多精细：16-bit 是 CD 标准，日常完全够用；24-bit 是专业录音的配置，后期调音余量更大。记住：采样率管“时间精度”，量化位数管“幅度精度”。

画面是同样的逻辑：分辨率（1080p/4K）是空间精度，帧率（30/60fps）是时间精度，码率是每秒给多少数据预算——画质和体积的总开关。编码（H.264/H.265）是压缩算法，格式（MP4/MOV）只是装视频的“盒子”。

导出时这些参数怎么选

  • 画面：分辨率 + 帧率：1080p/30fps 是万金油；4K/60fps 给高要求和后期裁剪留余量
  • 编码 + 格式：H.264 + MP4：兼容性之王，手机电脑网站全能播；H.265 体积小一半但老设备可能播不动
  • 码率：画质的总开关：1080p 给 8~12Mbps，4K 给 35~45Mbps；码率不够，4K 也糊
  • 音频：48000Hz + 16-bit：视频行业标准采样率；16-bit 足够用，24-bit 留给专业录音后期
  1. 先定用途：发短视频平台，还是存档收藏
  2. 分辨率帧率二选一：1080p/30fps 日常，4K/60fps 高要求
  3. 编码格式抄作业：H.264 + MP4
  4. 码率按分辨率给够：1080p 配 8~12Mbps
  5. 音频直接选 48000Hz + 16-bit，不用纠结
