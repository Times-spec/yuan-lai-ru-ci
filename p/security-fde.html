FDE：给整块硬盘上锁

电脑丢了，硬盘里的数据怎么办？
👀 日常场景

笔记本送修、旧电脑挂闲鱼、公司发的电脑要归还——硬盘里躺着微信聊天记录、工资条、客户资料。你以为“删掉”就干净了？数据恢复软件能把删掉的文件捞回来大半。FDE（全盘加密）就是给整块硬盘上的一把锁：没钥匙，硬盘拆下来也是一块“砖头”。

原理：它是怎么运作的

💡 整盘数据先加密再落盘，密钥由开机密码+TPM 芯片守护——硬盘离身也读不出东西。

先看全过程

  1. 数据写入硬盘前，先用密钥整盘加密
  2. 密钥存进 TPM 芯片并由开机密码保护
  3. 开机时 TPM 验明硬件无篡改才放行密钥
  4. 系统运行时透明加解密，用户无感
  5. 硬盘被拔走：没有密钥，读出的全是乱码

FDE（Full Disk Encryption，全盘加密）解决的是一个很具体的问题：电脑丢了、送修了，硬盘里的数据怎么办？删文件、设开机密码都防不住——把硬盘拔下来插到别的电脑上，文件照读不误。FDE 的思路是釜底抽薪：数据写进硬盘之前，先用一把密钥整体加密，读出来时再解密。没有密钥，整盘就是一堆乱码。

密钥本身由两层保护：第一层是你的开机密码/PIN，第二层是 TPM 芯片（主板上一颗专门存密钥的安全芯片，防拆防读）。开机时 TPM 确认“硬件没被动过”才放行密钥，全程你几乎无感——这就是它和“给单个文件设密码”最大的区别：粒度粗（整盘），但零打扰。

和它常被混淆的是文件级加密（如 EFS、压缩包密码）：后者只保护挑出来的文件，临时文件、交换分区里的痕迹照样明文躺着；FDE 是连操作系统、虚拟内存、回收站一起锁死。当然它也有边界：只防“硬盘离身”（静态数据），电脑开着、你登录着的时候，数据是解密状态，木马和锁屏绕过照样能偷——所以 FDE + 强锁屏密码才是完整姿势。

我该怎么开启它

  • BitLocker（Windows）：系统自带：设置 → 隐私和安全性 → 设备加密（或控制面板 → BitLocker 加密）
  • FileVault（macOS）：系统设置 → 隐私与安全性 → FileVault，打开后整盘加密
  • LUKS（Linux）：装系统时勾选“加密磁盘”，或用 cryptsetup 给数据盘加密
  1. 先备份重要数据：加密本身很安全，但以防万一
  2. 按上面的路径打开对应开关，跟着向导一步步走
  3. 系统会生成一串恢复密钥（Windows 是 48 位数字）——立刻抄下来
  4. 把恢复密钥存到和电脑不同的地方：纸上、靠谱的云笔记，或交给家人
  5. 加密在后台慢慢进行，期间可以正常用电脑；完成后重启验证一次
