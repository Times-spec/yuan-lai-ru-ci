多语言/地区自动跳转

你在哪儿，它就带你去哪儿的版本
👀 日常场景

第一次打开某国际品牌的官网，明明输入的是 .com，页面却自动变成了中文版；出国旅游打开订票网站，货币自动切成了当地币种。网站在根据你的“位置”，把你送到对的版本。

原理：它是怎么运作的

💡 服务端根据请求的 IP 地理位置或浏览器语言偏好（Accept-Language），自动 302 到对应语言或地区的站点版本。

先看全过程

  1. 浏览器发请求并带上语言偏好
  2. 服务端解析 IP 归属地
  3. 匹配最合适的语言地区版本
  4. 302 跳转到对应版本网址
  5. 用户可手动切换并记住选择

多语言/地区自动跳转是国际站点的“迎宾员”：第一次访问时，服务端看你浏览器的 Accept-Language（语言偏好）或你 IP 的归属地，自动 302 到对应的版本，比如 /zh-cn/ 或 /en-us/。实现不难，难的是分寸：搜索引擎官方其实不推荐粗暴自动跳转，因为爬虫可能被误判地区导致收录错乱，正确姿势是配 hreflang 标签告诉搜索引擎各版本的关系；对用户则要永远留一个显眼的手动切换入口，并把用户的选择存进 Cookie，下次优先尊重——否则用 VPN 出差的人每次都会被“纠正”到错误的语言。记住原则：自动跳转是建议，不是强制；只按 IP 判断会误伤海外华人，语言偏好和手动选择同样重要。实现上通常只在首次访问时做一次判断：读 Accept-Language 或查 GeoIP，302 到对应版本，同时在页面角落放切换器。用户一旦手动切换，就把选择写进 Cookie，以后都优先尊重。记住一个反例：把爬虫也 302 来 302 去，会导致搜索引擎只收录单一版本，多语言 SEO 直接报废。

开发者：应该如何接入

  • GeoIP 库：MaxMind GeoIP2 按 IP 判国家
  • Accept-Language：读浏览器语言偏好，零成本
  • CDN 边缘规则：边缘函数按国家头分流
  1. 确定分流维度：按国家（GeoIP）还是按语言（Accept-Language）
  2. 首次访问时判断并 302 到对应版本（如 /zh-cn/）
  3. 页面显眼位置放语言/地区切换器
  4. 把用户手动选择存 Cookie，下次优先尊重它
  5. 加 hreflang 标签告诉搜索引擎各版本关系
